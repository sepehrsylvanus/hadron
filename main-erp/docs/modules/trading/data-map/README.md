# نقشهٔ دادهٔ ماژول بازرگانی

این پوشه دو فایل مستقل دارد؛ هیچ‌کدام به build پروژه وابسته نیست.

| فایل | توضیح |
|---|---|
| `hadron-data-map-v2.html` | نسخهٔ ادیت‌شدهٔ نقشهٔ داده (۶۸۷ کیلوبایت، تک‌فایل، آفلاین). ماژول بازرگانی بازنویسی شده: **۳۳ جدول / ۵۱۲ ستون / ۱۱ زیرگروه**، شامل نمایش‌گر مدل Prisma. |
| `trading.prisma` | اسکیمای پیشنهادی و قابل اجرای بازرگانی: ۳۳ مدل، ۲۱ enum، ۵۱۲ ستون، ۱۰۲ رابطه. با `prisma validate` بدون خطا. |

## باز کردن نقشه

فایل HTML را در مرورگر باز کنید (بدون سرور کار می‌کند). در ماژول **بازرگانی**:

- هر جدول یک کارت است؛ زیرگروه‌ها در ستون کناری فیلتر می‌کنند.
- منوی خروجی ← **«مدل Prisma بازرگانی»**: متن کامل `trading.prisma` را برای کپی/دانلود نشان می‌دهد.
- تغییرات در `localStorage` نگه داشته می‌شوند؛ کلید ذخیره‌سازی `hadron.datamap.v3` است تا وضعیت نسخهٔ قبلی روی مدل جدید نیفتد.

## تفاوت با نسخهٔ اصلی

نسخهٔ اصلی (`hadron-data-map.html`) دست‌نخورده است. این نسخه از روی همان فایل ساخته شده و فقط ماژول بازرگانی آن جایگزین شده است:

- جداول پراکندهٔ فورواردر / ادارهٔ گمرک / مرجع‌ها در `TradeParty` + `TradePartyRole` + `TradeReferenceValue` ادغام شدند.
- پروندهٔ ترکیبی ارز به `FxFile` + `FxAllocation` + `FxReceipt` + `Collateral` تفکیک شد.
- `costs` تک‌دامنه به `TradeCost` + `CostAllocation` (چند بخش + مجموع) تبدیل شد.
- اقلام سفارش و محموله، بیمه، بازرسی، رفع تعهد و کد ۸ رقمی با قفل ویرایش اضافه شدند.

مسیرها: `/trading/{references,parties,projects,orders,fx,insurance,shipments,customs,commitments,costs,reports}`.
