گام 01

قبل از شروع: دقیقاً چه چیزی می‌سازیم؟

این دفترچه مسیر ساخت یک بک‌اند آزمایشی مستقل است؛ نه مهاجرت ERP فعلی به Nest و نه ساخت تمام Data Map. خروجی اولیهٔ دستورها: monorepo، Schema محدود، اتصال Prisma، health check، پوستهٔ React و تست‌های منطق نمونه است. APIهای تجاری فصل‌های بعد قرارداد و دستور ساخت‌اند و هنوز سرویس آماده نیستند.

داخل محدودهخارج محدوده
محصول، قطعه، کامپوننت؛ تأمین‌کننده و منابع تأمین موردنیاز موادمالی، فروش، خزانه، همکاری و داشبورد عمومی ERP
BOM و محاسبهٔ نیاز مواد و snapshotهای آنسفارش خرید/رسید، گردش کامل انبار، سفارش تولید و مراکز کاری
بازرگانی: ثبت اولیهٔ پروژه و سربرگ ثبت سفارش تا مرحلهٔ فعلیاقلام/مجوز سفارش، FX، بیمه، حمل، گمرک، تعهد، هزینه و مراحل آینده
مرجع واحد/ارز/کشور و ارجاع مسئول/مالک فقط در حد نیازماژول کامل مدیریت هویت، سازمان، کارت و پروانهٔ بازرگانی
React فقط صفحهٔ وضعیت اتصالهیچ صفحهٔ عملیاتی محصولات، BOM، MRP، تأمین‌کننده یا بازرگانی
۴۲ مدل به معنی ۴۲ صفحه یا ۴۲ قابلیت جدید نیست: ۲۹ جدول دامنه/ورودی و خروجی snapshot + ۱۳ جدول پشتیبان. انتخاب صریح در scope.json است؛ انتخاب کل schema یا گسترش خودکار از روی FK ممنوع است.

گام 11

Migration اولیه؛ checkpoint اجباری بازبینی

فقط روی دیتابیس تازه و مستقل آزمایش. ابتدا SQL را بساز، ولی هنوز deploy نکن:

shell

فایل prisma/migrations/<timestamp>_initial_scoped_lab/migration.sql را باز کن. باید فقط ۸ schema انتخاب‌شده، ۴۲ جدول و enumهایشان را داشته باشد؛ ساخت جدول finance/sales/production یا inventory.transactions نشانهٔ خطاست.

  • تمام ردیف‌های UNKNOWN-nullability-nullable-in-lab و lab-explicit-precision-not-in-map در decisions.json را تصمیم‌گیری کن.
  • SQL مکمل prisma/legacy-checks.sql و سپس prisma/legacy-indexes.sql را پس از DDL اولیه، با بازبینی به همان migration.sql اضافه کن؛ دوباره در اجرای بعدی append نکن.
  • سه partial unique: BOM تأییدشدهٔ والد، منبع تأمین ترجیحی فعال و تماس اصلی فعال؛ بدون آن‌ها race واقعی کنترل نمی‌شود.
  • برای Trading، unique شمارهٔ پروژه، unique سراسری orderNumber، مبلغ مثبت و version≥1 را اضافه کن؛ SQL نمونه پایین است.
  • SQL منبع، trigger، RLS، tenant policy و auditing خودکار کامل را توصیف نمی‌کند؛ Prisma به‌تنهایی این‌ها را ایجاد نکرده است.
  • در migration dev اگر prompt reset یا drift دیدی، توقف کن. helper عمداً reset و db push ندارد.

الگوی transaction و قفل؛ چطور service بنویسی؟

برای هر command: مجوز → DTO → transaction → lock/expectedVersion → اعتبار مراجع و قواعد → write → audit → commit → response محدود. Controller نباید data: body را مستقیم به Prisma بدهد.

TypeScript — pseudo-service؛ notFound/DTO/audit را پیاده کن
// الگوی سرویس، نه endpoint آماده؛ ورودی‌ها از DTO معتبر آمده‌اند.
await db.$transaction(async tx => {
  const rows = await tx.$queryRaw<{id:string,version:number}[]>`
    SELECT id, version FROM trading.order_registrations
    WHERE id = ${orderId}::uuid FOR UPDATE`;
  if (!rows.length) throw notFound();
  assertVersion(expectedVersion, String(rows[0].version));
  // project status + identity scope + any external linkage: re-check under lock.
  // updateMany WHERE { id, version } with explicit fields, version increment.
  // append trade_audit_events for this order inside THIS transaction.
  // count !== 1 => conflict; throwing rolls back both writes.
}, { isolationLevel: 'Serializable' });

Serializable ممکن است P2034 بدهد: retry محدود فقط برای خطای retryable و فرمان idempotent با request key معتبر. unique violation را بی‌قید retry نکن. P2002 → conflict، P2003 → مرجع نامعتبر، P2025 → not found/conflict با قرارداد مشخص؛ متن خام SQL را به کاربر نده.

برای شماره‌گذاری، sequence یا counter با lock؛ MAX(number)+1 با تست تکی هم ناامن است. برای اجرای run طولانی transaction را در تمام محاسبه باز نگه ندار؛ snapshot را capture کن، محاسبهٔ خالص را انجام بده و نتیجه را با وضعیت صحیح منتشر کن.

دریافت امن تغییرات Git

شاخهٔ تحویل arena/d5f0785f-hadron است، نه a9. بدون PR و بدون force. راه بی‌تعارض با کار محلی: از پوشهٔ والد، clone تازه با نام جدید بگیر:

shell
git clone --single-branch --branch arena/d5f0785f-hadron https://github.com/sepehrsylvanus/hadron.git hadron-nx-guide
cd hadron-nx-guide

اگر روی شاخهٔ صحیح و working tree تمیز هستی:

shell
git status --short --branch
git branch --show-current
# فقط اگر شاخه arena/d5f0785f-hadron و وضعیت کاملاً تمیز است:
git pull --ff-only origin arena/d5f0785f-hadron
اگر شاخه متفاوت، فایل تغییرکرده/جدید یا تاریخچهٔ واگرا داری، توقف کن. دستور pull --ff-only در حالت واگرا متوقف می‌شود و conflict را خودکار حل نمی‌کند. هیچ تضمین مطلق بدون دیدن وضعیت سیستم تو وجود ندارد. reset --hard، clean -fd و stash pop کورکورانه راه این تحویل نیستند.

اسکریپت PowerShell با کنترل شاخه و dirty tree در ../../docs/SAFE-UPDATE-FA.md نسبت به workspace و در ../docs/SAFE-UPDATE-FA.md نسبت به همین HTML قرار دارد. بعد از pull، دستورهای ERP قبلی از main-erp اجرا می‌شوند؛ secret و taskهای محلی نیازمند بررسی مسیر جدید هستند.

const D=Decimal.clone({precision:80,rounding:Decimal.ROUND_HALF_UP});
export class DomainError extends Error { constructor(readonly code:string){super(code);} }
export function positiveAmount(value:string):string {
  if(!/^(?:0|[1-9]\d{0,17})(?:\.\d{1,6})?$/.test(value)||!new D(value).gt(0)) throw new DomainError('INVALID_AMOUNT');
  return new D(value).toFixed();
}
export function assertVersion(expected:string,actual:string){
  if(!/^[1-9]\d*$/.test(expected)||expected!==actual) throw new DomainError('VERSION_CONFLICT');
}
export type Bom=Record<string,{baseOutputQty:string,lines:{childId:string,usageQty:string,scrapPercent:string}[]}>;
// Lab convention: scrap is an additive consumption allowance, not a yield-loss divisor.
export function explodeBom(root:string,quantity:string,graph:Bom):Record<string,string>{
  if(!new D(quantity).isFinite()||!new D(quantity).gt(0)) throw new DomainError('INVALID_QUANTITY');
  const totals=new Map<string,Decimal>();let visits=0;
  function visit(id:string,qty:Decimal,path:Set<string>){
    if(path.has(id)) throw new DomainError('BOM_CYCLE');
    if(++visits>10000||path.size>=64) throw new DomainError('BOM_TOO_COMPLEX');
    const node=graph[id];if(!node)return;
    const base=new D(node.baseOutputQty);
    if(!base.isFinite()||!base.gt(0)) throw new DomainError('INVALID_BASE_OUTPUT');
    const next=new Set(path);next.add(id);
    for(const line of node.lines){
      const usage=new D(line.usageQty),scrap=new D(line.scrapPercent);
      if(!usage.isFinite()||!usage.gt(0)||!scrap.isFinite()||scrap.lt(0)||scrap.gt(100)) throw new DomainError('INVALID_BOM_LINE');
      const required=qty.div(base).mul(usage).mul(new D(1).plus(scrap.div(100)));
      totals.set(line.childId,(totals.get(line.childId)??new D(0)).plus(required));
      visit(line.childId,required,next);
    }
  }
  visit(root,new D(quantity),new Set());
  return Object.fromEntries([...totals].sort(([a],[b])=>a.localeCompare(b)).map(([id,qty])=>[id,qty.toFixed()]));
}
export function netMaterial(gross:string,onHand:string,firmReceipts:string,safety:string){
  const values=[gross,onHand,firmReceipts,safety].map(x=>new D(x));
  if(values.some(x=>!x.isFinite()||x.lt(0)))throw new DomainError('INVALID_MRP_INPUT');
  const [g,h,r,s]=values;return D.max(0,g.plus(s).minus(h).minus(r)).toFixed();
}
export function assertOrderEditable(projectStatus:string,orderStatus:string,hasLinkedFx:boolean){
  if(['CLOSED','CANCELLED'].includes(projectStatus))throw new DomainError('PROJECT_CLOSED');
  if(orderStatus!=='DRAFT')throw new DomainError('ORDER_NOT_DRAFT');
  if(hasLinkedFx)throw new DomainError('ORDER_HAS_LINKED_FX');
}
export function assertOrderTransition(from:string,to:string,reason:string,correction=false){
  if(!reason.trim())throw new DomainError('REASON_REQUIRED');
  const normal:Record<string,string[]>={DRAFT:['SUBMITTED','CANCELLED'],SUBMITTED:['ACTIVE','SUSPENDED','CANCELLED'],ACTIVE:['SUSPENDED','CANCELLED'],SUSPENDED:['ACTIVE','CANCELLED'],CANCELLED:[]};
  const backward:Record<string,string[]>={SUBMITTED:['DRAFT'],ACTIVE:['SUBMITTED'],SUSPENDED:['SUBMITTED']};
  if(!normal[from]?.includes(to)&&!(correction&&backward[from]?.includes(to)))throw new DomainError('INVALID_TRANSITION');
}

export const PublicHealth = () => SetMetadata('publicHealth', true);
// Development service token only. This is NOT user login, RBAC or production authentication.
@Injectable()
export class LabGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}
  canActivate(context: ExecutionContext): boolean {
    if (this.reflector.getAllAndOverride<boolean>('publicHealth', [context.getHandler(),context.getClass()])) return true;
    if (process.env.NODE_ENV === 'production') throw new UnauthorizedException('Lab credentials disabled in production');
    const expected = process.env.LAB_API_TOKEN ?? '';
    const value = context.switchToHttp().getRequest().headers.authorization;
    const supplied = typeof value === 'string' && value.startsWith('Bearer ') ? value.slice(7) : '';
    const a = Buffer.from(expected), b = Buffer.from(supplied);
    if (a.length < 64 || a.length !== b.length || !timingSafeEqual(a,b)) throw new UnauthorizedException();
    return true;
  }
}
